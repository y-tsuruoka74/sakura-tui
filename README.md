# sakura-tui

さくらインターネットのサービスをターミナルから操作する TUI（[ratatui](https://ratatui.rs) 製）。

`s` キーでサービスを切り替えて使います（24 種類）。

### コンテナレジストリ
- レジストリの一覧・詳細・作成・編集・削除
- レジストリユーザーの一覧・追加・編集・削除
- イメージ（リポジトリ、タグ、サイズ、レイヤ数、プラットフォーム、ビルド日時）の閲覧と削除

### AppRun（共用型）

> [!IMPORTANT]
> AppRun API を使うには 2 つの前提があります。どちらが欠けても `403 Forbidden` になります。
> 1. **API キーの作成時に「AppRun」の権限にチェック**が入っていること（アクセスレベルとは別の項目です）
> 2. **AppRun のユーザーが作成済み**であること
>    ```sh
>    curl -X POST -u "$SAKURA_ACCESS_TOKEN:$SAKURA_ACCESS_TOKEN_SECRET" \
>      https://secure.sakura.ad.jp/cloud/api/apprun/1.0/apprun/api/user
>    ```
>
> 403 が返ったときは TUI 上にもこの案内を表示します。

- アプリケーションの一覧とステータス
- 公開URL、スケール設定、ポート、デプロイ元のコンテナイメージ
- バージョン一覧とトラフィックの振り分け（`t` で選択中バージョンへ 100%）

### AppRun 専有型（閲覧のみ）
- クラスタの一覧と詳細（ポート、サービスプリンシパル、Let's Encrypt 設定）
- クラスタに属するアプリケーション（稼働中バージョン、台数、クールダウン）
- オートスケーリンググループと、その配下のワーカーノード（状態・draining・世代）
- 証明書（コモンネーム、有効期限）

> [!NOTE]
> 専有型は**閲覧のみ**です。クラスタやポートの作成・変更、証明書の登録はコントロールパネルで行ってください。
> 共用型とは別のエンドポイント（`/cloud/api/apprun-dedicated/1.0`）で、リソース体系も別です。

### サーバー（IaaS）
- ゾーンごとのサーバー一覧（電源状態・プラン・IPアドレス）
- ディスク、NIC、タグを含む詳細
- 起動・シャットダウン・強制停止・強制リセット
- `z` でゾーンを切り替え

### IaaSリソース（閲覧のみ）
- ディスク（容量、プラン、接続方式、接続サーバー、暗号化）
- ルータ＋スイッチ（帯域、スイッチ、ネットワーク、マスク長、ゲートウェイ）
- ロードバランサ、VPCルータ、データベース、NFSアプライアンス
- 一覧には名前、状態、プラン、接続先、IDを表示し、右ペインでサービス固有情報を確認
- すべてゾーン切り替え、絞り込み、リソースIDのコピーに対応

### ストレージ・アプリケーション連携（閲覧のみ）
- オブジェクトストレージの全サイトを横断したバケット一覧（サイト、リージョン、S3エンドポイント、プラン）
- シンプルMQのキュー一覧（可視性タイムアウト、未処理メッセージ保存期間）
- イベントバスのスケジュール、トリガー、処理設定（イベントソース、実行間隔、宛先など）
- ワークフロー一覧（公開状態、ログ設定、同時実行モード、タグ）
- いずれも絞り込み、更新、リソースIDのコピーに対応

### CDN・自動運用・マネージドDB（閲覧のみ）
- ウェブアクセラレータのサイト一覧（状態、ドメイン、オリジン、キャッシュTTL、証明書）
- オートスケール設定（トリガー、対象ゾーン、停止状態、登録元）
- エンハンスドデータベース（DB種別、リージョン、ホスト、ポート）
- いずれも絞り込み、更新、リソースIDのコピーに対応

### スイッチ
- ゾーンごとのスイッチ一覧
- 名前、説明、ID、タグ、作成日時
- 接続中のサーバー数とアプライアンス数
- スイッチの作成・編集・削除（接続中のリソースがある場合は削除を停止）
- `z` でゾーンを切り替え

### DNS
- ゾーン一覧とレコード（名前・種別・値・TTL）
- 委任先のネームサーバー
- DNSゾーンの作成・説明編集・削除
- レコードの追加・編集・削除（設定ハッシュによる更新競合の検出）

### シンプル監視
- 監視の一覧（有効/停止、監視対象、種別、間隔）
- プロトコル・ポート・パス・期待ステータス・通知先
- ping / TCP / HTTP / HTTPS監視の作成・編集
- 監視の有効／停止切り替えと削除

### シークレットマネージャ
- Vault 一覧とシークレット名・最新バージョン
- Vaultの作成・編集・削除
- シークレットの登録・新バージョン登録・削除
- 値は一覧では常に伏せ字。`u` を押して確認ダイアログに答えたときだけ取得します

### モニタリングスイート
- アラートプロジェクトとルール（発報中かどうかを色分け）
- アラートプロジェクトの作成・編集・削除
- アラートルールの作成・編集・削除（警告／重大しきい値と継続時間）
- ログ計測ルールの作成・編集・削除（公式v1マッチャーJSONを完全保持）
- クラウドリソースからログストレージへの転送設定の作成・編集・削除
- クラウドリソースからメトリクスストレージへの転送設定の作成・編集・削除
- 転送元のパブリッシャー／バリアントをAPIから取得して選択
- ダッシュボードプロジェクトの作成・編集・削除
- 発報履歴（深刻度・継続中/復旧・値としきい値）
- シンプル通知／EventBusの通知先と、再送間隔・ラベル条件付き通知経路の作成・編集・削除
- 通知経路を `[` / `]` で上下に並べ替え
- ログ／メトリクス／トレースの保管先
- ログ／メトリクス／トレースストレージの作成・名前／説明編集・削除
- ログ／トレースストレージの保持期間変更
- ストレージアクセスキーの作成・説明編集・削除と、確認後のシークレット表示
- アクセスキーはユーザ領域ストレージだけが対象（システム領域ではAPIを呼びません）

### 共通
- サービス切り替えは独立した全画面ページで、カテゴリ／サービスの2ペイン表示。`←` / `→` でカテゴリ、`↑` / `↓` でサービスを選択
- リストの絞り込み（`/`）、選択項目のクリップボードへのコピー（`y`）
- usacloud プロファイルの切り替え（`p`）

起動時は**読み取り専用モード**です。書き込み系の操作は `w` キーで明示的にモードを切り替えてから行います。
通常起動では最初にサービス選択画面を表示します。`--service` を指定した場合だけ、そのサービスを直接開きます。

## インストール

```sh
cargo build --release
./target/release/sakura-tui
```

### コマンドラインオプション

```
  -p, --profile <名前>   使う usacloud プロファイル
  -z, --zone <ゾーン>     ゾーン依存のサービスで使うゾーン (例: is1a)
  -s, --service <名前>    起動時に開くサービス
                         server / disk / registry / apprun / dedicated /
                         switch / internet / loadbalancer / vpcrouter /
                         database / nfs / object-storage / simplemq /
                         enhanced-db / eventbus / workflows / webaccel /
                         autoscale / dns / secrets / monitor / monitoring /
                         account / billing
      --trace            APIリクエストを標準エラーに記録する
  -h, --help             ヘルプ
  -V, --version          バージョン
```

`--trace` は TUI が画面を占有するため、`sakura-tui --trace 2>trace.log` のように
リダイレクトして使います。

## 認証

### さくらのクラウド API

以下の順で探します。

1. 環境変数
   ```sh
   export SAKURA_ACCESS_TOKEN=xxxxxxxx          # SAKURACLOUD_ACCESS_TOKEN も可
   export SAKURA_ACCESS_TOKEN_SECRET=xxxxxxxx   # SAKURACLOUD_ACCESS_TOKEN_SECRET も可
   ```
2. usacloud のプロファイル（`~/.usacloud/<プロファイル名>/config.json`）

   プロファイル名は `SAKURA_PROFILE` / `SAKURACLOUD_PROFILE` / `USACLOUD_PROFILE`、
   指定がなければ `~/.usacloud/current` の内容、それも無ければ `default` を使います。
   既に `usacloud config` を済ませていれば設定不要です。

どちらも見つからない場合でもアプリは終了せず、初期設定フォームを表示します。
名前・アクセストークン・シークレット・既定ゾーン・保存先を入力すると、検証後に保存して
そのままサービス選択画面へ進みます。

起動後は `p` キーでピッカーを開き、環境変数・usacloud プロファイル・キーチェーンに預けた
資格情報のあいだを切り替えられます。切り替えはそのセッション限りで、
`~/.usacloud/current` は書き換えません。

ピッカー内のキー:

| キー | 動作 |
| --- | --- |
| `Enter` | 選択した資格情報に切り替え |
| `n` | 資格情報を新規作成 |
| `c` | 表示色を割り当て（似た名前を見分けるため） |
| `d` | 削除（キーチェーンに保存したもののみ） |

### 資格情報の新規作成

初回起動時、または `p` → `n` で作成フォームが開きます。名前・アクセストークン・シークレット・既定ゾーンを入力し、
保存先を選びます。**保存前に API を 1 回呼んでトークンが通ることを確かめる**ので、
打ち間違えたトークンが保存されることはありません。

| 保存先 | 保存場所 | 他ツールとの共用 | 平文 |
| --- | --- | --- | --- |
| usacloud 互換 | `~/.usacloud/<名前>/config.json`（0600） | usacloud CLI / Terraform / Packer から使える | 残る |
| キーチェーン | OS のキーチェーン + 設定ファイルに名前とゾーンのみ | この TUI からのみ | 残らない |

> [!NOTE]
> `~/.usacloud` は `sacloud/api-client-go` が読む共通の場所で、usacloud CLI のほか
> Terraform provider や Packer plugin も同じ仕組みを使います。キーチェーンを選ぶと
> 平文は残りませんが、それらのツールからはその名前で認証できなくなります。
>
> 削除できるのはキーチェーンに保存したものだけです。usacloud のプロファイルは
> 他のツールも使うため、この TUI からは消しません。

### コンテナレジストリ（イメージ一覧）

イメージ一覧はクラウド API では取得できないため、レジストリの FQDN に対して
Docker Registry HTTP API V2 を直接呼びます。そのため **クラウド API のトークンとは別に、
レジストリユーザーの ID / パスワード** が必要です。

イメージタブで `L` を押すとログインダイアログが開きます。「設定に保存」を有効にすると
次回以降は自動でログインします。

**パスワードは OS のキーチェーンに保存され、設定ファイルには書き込みません。**
macOS はキーチェーン、Windows は資格情報マネージャー、Linux は Secret Service を使います。
設定ファイルに残るのはユーザー名だけです。

```toml
[registries."example.sakuracr.jp"]
username = "your-registry-user"
```

`O` キーで破棄すると、設定ファイルとキーチェーンの両方から消えます。
設定ファイルの場所は `SAKURA_TUI_CONFIG` で変更できます。

> [!NOTE]
> 以前のバージョンが設定ファイルに平文で保存したパスワードは、起動時に自動でキーチェーンへ移し、
> 設定ファイルからは削除します。
>
> キーチェーンが使えない環境（Secret Service の無いサーバなど）では、平文へ退避せず
> **保存自体を行いません**。その場合ログイン情報は起動中のみ有効です。

| `t` | シンプル監視: 選択中の監視を有効化 / 停止（書き込みモード） |
| `t` | モニタリング: ログ／トレースストレージの保持期間を変更（書き込みモード） |
| `z` | ゾーンを切り替え（サーバー / スイッチ / モニタリング） |
| `u` | シークレットの値を表示（確認あり） |
| `u` | モニタリング: アクセスキーのシークレットを表示（確認あり） |
| `[` / `]` | モニタリング: 通知経路を上 / 下へ移動（書き込みモード） |

| `/` | 表示中のリストを絞り込み（`Enter` 確定 / `Esc` 解除） |
| `y` | 選択項目をコピー（タグなら `<FQDN>/<repo>:<tag>`） |
| `p` | 認証情報の切り替え・作成・削除 |

サービス選択画面は端末の高さに合わせて自動的にスクロールします。`PgUp` / `PgDn` で
5サービスずつ、`g` / `G` で先頭 / 末尾へ移動できます。

ユーザーの編集ではパスワードを空欄のままにすると、権限だけを変更します。

絞り込みはペインごとに独立して保持されます。

### 操作モード

事故を防ぐため、起動時は**読み取り専用モード**です。ヘッダーに現在のモードが出ます。

| モード | 表示 | できること |
| --- | --- | --- |
| 読み取り専用（既定） | `読取専用`（緑） | 閲覧、絞り込み、コピー、レジストリへのログイン |
| 書き込み | `書込可`（赤・反転） | 上記に加えてユーザー管理、レジストリ / スイッチ / DNS / シンプル監視の管理、イメージ削除、トラフィック切替、サーバーの電源操作 |

読み取り専用のあいだは書き込み系のキーが無効になり、キーヒントにも出ません。
レジストリへのログイン（`L`）はイメージの閲覧に必要なため、読み取り専用でも使えます。

### 危険な操作について

- **レジストリの削除**（`D`）は取り消せず、保存されている全イメージとユーザーが消えるため、
  確認ダイアログでレジストリ名の入力を求めます。
- **スイッチの削除**（`D`）は確認ダイアログを表示し、サーバーまたはアプライアンスが
  接続されている場合は API に送信せず停止します。
- **DNSレコードの削除**（レコードペインの `d`）は確認ダイアログを表示します。
  更新時に設定ハッシュを送るため、別の場所で先に変更されていれば競合として停止します。
- **DNSゾーンの削除**（ゾーンペインの `D`）は全レコードも復元不能になるため、
  確認ダイアログでゾーン名の入力を求めます。
- **シンプル監視の削除**（`D`）は確認ダイアログを表示します。
- **Vaultの削除**（Vaultペインの `D`）は課金停止を伴うため、Vault名の入力を求めます。
- **シークレットの削除**（シークレットペインの `d`）は全バージョンが対象のため、シークレット名の入力を求めます。
- **アラートプロジェクトの削除**（`D`）はプロジェクト名の入力を求めます。
- **アラートルールの削除**（ルールペインの `d`）はルール名の入力を求めます。
- **ログ計測ルールの削除**はログからのメトリクス生成を停止するため、ルール名の入力を求めます。
- **ログ転送設定の削除**は対象リソースからのログ収集を停止します。確認ダイアログを表示します。
- **通知先の削除**は、参照中の通知経路がある場合APIに拒否されます。先に通知経路を削除してください。
- **通知経路の削除**後は、一致するアラートがその経路から通知されなくなります。
- **モニタリングストレージの作成**は作成後に課金対象になります。削除時はストレージ名の入力を求めます。
- **ストレージ保持期間**を41日以上にすると追加料金が発生するため、変更前に確認します。
- **ストレージアクセスキーの削除**後は、そのキーを使う送信処理が認証できなくなります。
- **イメージの削除**（イメージタブのタグペインで `d`）は Registry API の仕様上
  マニフェスト単位で行われるため、**同じダイジェストを指す他のタグも同時に消えます**。
  レジストリ側で削除が無効な場合は `405 Method Not Allowed` になります。
- **サーバーの強制停止 / 強制リセット**（`X` / `B`）は電源ケーブルを抜くのと同じで
  データが失われることがあるため、サーバー名の入力を求めます。
  通常のシャットダウン（`x`）と起動（`b`）は確認ダイアログのみです。
  現在の電源状態と噛み合わない操作（起動中のサーバーへの起動など）は API を叩く前に止めます。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/config.rs` | 認証情報の読み込み（環境変数 / usacloud プロファイル）と設定ファイルの保存 |
| `src/sacloud.rs` | さくらのクラウド API v1.1 クライアントの土台とコンテナレジストリ |
| `src/iaas.rs` | ゾーンとサーバー（電源操作を含む） |
| `src/switch.rs` | ゾーンごとのスイッチ一覧と件数 |
| `src/cloud_resources.rs` | ディスク、ルータ＋スイッチ、IaaSアプライアンスの共通閲覧クライアント |
| `src/managed_resources.rs` | オブジェクトストレージ、シンプルMQ、イベントバス、ワークフローの共通閲覧クライアント |
| `src/apprun.rs` | AppRun 共用型 API クライアント |
| `src/apprun_dedicated.rs` | AppRun 専有型 API クライアント（閲覧のみ、カーソル方式のページング） |
| `src/commonservice.rs` | DNS とシンプル監視（コンテナレジストリと同じ commonserviceitem） |
| `src/secretmanager.rs` | シークレットマネージャ（値の取得は明示操作のときだけ） |
| `src/monitoring.rs` | モニタリングスイート（アラート・保管先） |
| `src/registry.rs` | Docker Registry HTTP API V2 クライアント（Bearer / Basic 認証に対応） |
| `src/http.rs` | リトライ（429・5xx・接続エラー）とトレースログの共通処理 |
| `src/keychain.rs` | レジストリのパスワードを OS のキーチェーンに預ける |
| `src/app/` | 画面状態とキー入力。`mod.rs` が共通部分、サービスごとに `apprun.rs` / `dedicated.rs` / `server.rs` / `switch.rs` |
| `src/ui/` | 描画（サービスごとのビューと共通のダイアログ） |

API 呼び出しは全て `tokio::spawn` して結果をチャネルで受け取るため、通信中も UI は止まりません。
一時的な失敗（429・5xx・接続エラー）は指数バックオフで最大3回まで送り直します。
`Retry-After` ヘッダがあればその指示に従います。

## 制限

- コンテナレジストリ、AppRun、シークレットマネージャ、マネージドサービス群はゾーンに依存しません。ゾーン切り替えはIaaSリソースとモニタリングスイートに効きます。
- さくらのクラウド API は GET のリクエストボディを読まないため、検索条件はクエリ文字列で送っています。
- 公開設定（`public`）は表示のみです。さくら側で廃止予定の項目のため、作成時は常に「非公開」になります。
- タグの詳細（サイズ・レイヤ数など）は選択中のタグの分だけ取得します。
- AppRun（共用型）はアプリの作成・削除・デプロイには未対応です（閲覧とトラフィック切替のみ）。
- AppRun（専有型）は閲覧のみです。ロードバランサとサービスクラスの一覧は未対応です。
- DNSゾーン名はサービス仕様上、作成後に変更できません。編集できるのは説明のみです。
- シンプル監視の編集フォームは ping / TCP / HTTP / HTTPS に対応します。その他の方式は閲覧・有効／停止・削除のみ対応します。
- モニタリングスイートの専有プラン作成時の暗号化・KMS・サービスプリンシパル指定は未対応です。
- スイッチに対するサーバーやアプライアンスの接続・切断操作には未対応です。
- サーバーは作成・削除・プラン変更には未対応です（閲覧と電源操作のみ）。
