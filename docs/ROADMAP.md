# サービス実装ロードマップ

この文書は、sakura-tui に今後追加するサービスと実装順を管理します。
基本方針は、リソースを安全に把握できる閲覧機能を先に提供し、作成・変更・削除は
API仕様と誤操作防止の設計が固まったものから書き込みモードへ追加することです。

## 実装済み（閲覧機能）

| サービス | 最初の対応範囲 |
|---|---|
| エンハンスドロードバランサ | 一覧、状態、プラン、FQDN、VIP、リージョン、実サーバ数 |
| ローカルルータ | 一覧、状態、接続スイッチ、インターフェース、ピア、スタティックルート |
| KMS | 鍵一覧、状態、サービスクラス、鍵の由来、最新バージョン、タグ |
| シンプル通知 | 通知先・通知先グループ・ルーティング等の契約リソース一覧と詳細 |
| アーカイブ・ISOイメージ | ゾーン別一覧、容量、スコープ、ストレージ、作成日時 |

これらは一覧・詳細・件数・絞り込み・リソースIDコピーまでを読み取り専用で提供します。

## 共通の完了条件

- サービス選択画面にカテゴリ、件数、利用可否が表示される
- 一覧、詳細、絞り込み、更新、IDコピーが利用できる
- ゾーン依存・グローバルリソースの区別が公式仕様と一致する
- 未契約、権限不足、認証エラーを区別して表示する
- APIのページングと文字列・数値IDの揺れを吸収する
- レスポンス解析とサービス列挙に回帰テストがある
